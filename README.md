# 🗺️ Lingo Atlas

**Lingo Atlas** is a desktop-first, immersive language learning platform designed for self-directed learners.

It supports 8 languages and combines spaced repetition, grammar training, AI-style shadowing, and listening labs into a unified, gamified learning system.

---

# ✨ Key Features

## 📚 Multi-Level Curriculum (A1 → C1)
Five progressive levels for each language:
- Wayfarer (Beginner)
- Explorer
- Navigator
- Fluent Speaker
- Polyglot (Advanced)

---

## 🎯 Interactive Lesson Types

### 🧠 Vocabulary Trainer
- Spaced repetition flashcards
- Native audio pronunciation
- IPA support
- Flip animations

### 📖 Grammar Workshops
- Fill-in-the-blank exercises
- Multiple choice quizzes
- Instant rule explanations

### 🎤 Shadowing Mode
- Listen → Repeat → Compare
- Speech similarity scoring (simulated)

### 👂 Listening Labs
- Audio comprehension drills
- Progressive difficulty scaling

---

## 🧭 Smart Personalization
- Adaptive learning path engine
- Weak-skill detection
- AI-based lesson recommendations

---

## 📊 Progress System
- GitHub-style study heatmap (12-week tracking)
- Skill radar chart:
  - Reading
  - Writing
  - Listening
  - Speaking
- Mastered vocabulary gallery

---

## 🏆 Gamification
- XP-based leveling system
- Weekly & global leaderboards
- 12 achievement badges
- Streak tracking system

---

# 🛠️ Tech Stack

## Frontend
- React 18 + Vite
- TypeScript
- Tailwind CSS (custom “Cartographic Atlas” theme)
- Zustand (state management)
- React Router 6
- Lucide Icons

## Backend
- Node.js + Express
- TypeScript
- In-memory database (demo-ready, no setup required)
